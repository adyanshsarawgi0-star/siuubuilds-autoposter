siuubuilds-autoposter

siuubuilds-autoposter is a private publishing and analytics tool built solely for the creator of the YouTube channel SIUUBUILDS (@siuubuildz).

What this application does

  • Uploads original 3D animated YouTube Shorts created by the channel owner using the official YouTube Data API v3 (youtube.upload).
  • Reads basic video statistics (views, likes, comments) for the owner's own channel using youtube.readonly.
  • Tracks post history locally to prevent duplicate uploads.

Who can use it

This is an internal, single-creator workflow tool used only by the owner of @siuubuildz. It does not offer public accounts, third-party logins, or paid services.
